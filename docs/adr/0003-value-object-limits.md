# URL value-object limits

The code and the v2 design spec disagreed on several limits; these are the resolved values, enforced in the value-object constructors and mirrored by the column widths:

- **CustomAlias**: optional; 3–12 characters, `[a-zA-Z0-9-]`. Matches `urls.custom_alias VARCHAR(12)`. The zero value means "no alias".
- **Keyword**: 2–100 characters, `[a-zA-Z0-9-_]`; at most 10 per URL (`url.MaxKeywords`), enforced by the aggregate in `AddKeyword`/`SetKeywords` and on hydration. Matches `keywords.value VARCHAR(100)`. An invalid keyword is an error, never silently dropped.
- **ShortCode**: 6–10 base62 characters; generated by the `ShortCodeGenerator` port, never inside the aggregate.

Validation errors wrap the `errdefs` sentinels with `%w` so callers use `errors.Is`; sentinel messages carry no format verbs.
